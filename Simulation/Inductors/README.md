# SPICE-модель индуктивностей TDK VLS3012HBX-N

Двенадцать позиций `L0079`…`L0090` используют общую параметризованную подсхему
`MY_LIB_INDUCTOR.ckt`. Числа не хранятся в модели: они лежат в Excel и передаются
через DbLib строкой `Sim Netlist`

```text
@DESIGNATOR %1 %2 @MODEL PARAMS: Lval=@IND_L RDCval=@IND_RDC CPval=@IND_CP RPval=@IND_RP
```

Поля `IND_L`, `IND_RDC`, `IND_CP`, `IND_RP` — обычные скрытые параметры компонента.
Внешние узлы: **1 — Port 1**, **2 — Port 2**, полярности у обмотки нет.

## Структура

- `MY_LIB_INDUCTOR.ckt` — общая подсхема `MY_LIB_INDUCTOR 1 2`, только пассивные R/L.
- `Parameters.json` — параметры двенадцати артикулов, происхождение величин, ограничения
  и записанная проверка расчётов.
- `Tests/` — 36 входных JSON для Spice Sifter: 12 автономных схем
  (`inductor_L00xx_standalone.json`) и 24 запуска DbLib Component — по одному на каждую
  позицию для `MY_LIB.DbLib` и `MY_LIB_IEC.DbLib` (`inductor_L00xx_dblib_eskd.json`,
  `inductor_L00xx_dblib_iec.json`).
- `Results/` — полные отчёты Sifter (`*.result.json`) по каждому тесту.

В тестах путь модели относительный: `../MY_LIB_INDUCTOR.ckt`. Путь в Excel относительно
DbLib: `Simulation\Inductors\MY_LIB_INDUCTOR.ckt`.

## Электрическая схема и параметры

```text
1 --[ Rdc ]-- mid --+--[ Lmain ]--+-- 2
                    |             |
                 [ Rp ]        [ Cp ]
                    |
                    +--[ Rcore1 ]--[ Lcore1 ]-- 2   (ветвь отключена, R1val=1e9)
```

| Параметр | Смысл | Источник |

| `Lval` | номинальная индуктивность | паспорт, 1 МГц |

`f_SRF` и `|Z|max` в таблице — средние значения эталонных вариантов Simple и Precision из
официальных SPICE-файлов TDK. Сами файлы производителя в модель не копировались: из них
взяты только внешние измеримые характеристики (импеданс, фаза, переходный процесс).

## Условия и ограничения

- Расчёт при **+25 °C**, **DC bias 0 А**, малосигнальный AC и линейный переходный процесс.
- Не моделируются: насыщение сердечника (Isat), самонагрев (Itemp), зависимость
  индуктивности от подмагничивания и температуры, старение.
- Добротность при 1…10 МГц соответствует варианту Simple; у варианта Precision ESR в этом
  диапазоне до 2,8 раза выше, то есть модель оптимистичнее по потерям.
- Численные моделирования в Altium не заменяют проверку на макете.
