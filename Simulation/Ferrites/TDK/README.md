# SPICE-модели ферритов TDK MPZ2012S

Коммерческие исполнения используют шесть собственных моделей MY_LIB `MPZ2012S…AT000_TERRA.ckt`. Автомобильные ATD25 имеют отдельные шесть моделей `MPZ2012S…ATD25_MYLIB.ckt`, описанные ниже. Их текст и RLC-схема написаны с нуля, без чтения и копирования заводских SPICE-netlist и внутренних коэффициентов. Первоначальный подбор выполнен по S-параметрам TDK от 6 февраля 2025 года; окончательные коэффициенты уточнены методом чёрного ящика по результатам моделирования официальных TDK Precise от 8 июля 2016 года, включая сопротивление на постоянном токе. Поэтому описание «только по S-параметрам» для окончательного варианта было бы неполным.

## Точность и ограничения

Каждая модель содержит 43 положительных элемента R/L/C. Условия: 25 °C, малый сигнал, постоянный ток смещения 0 А. Рабочий интервал аппроксимации — 1 МГц–3 ГГц. Насыщение, саморазогрев, зависимость от тока и температуры, разброс экземпляров не моделируются. Внутренние номиналы не являются паспортными параметрами детали для подбора замен.

Максимальная относительная ошибка комплексного импеданса `|Z_MY_LIB − Z_TDK| / |Z_TDK|` на отдельной сетке из 1001 частоты:

| MPN | Ошибка относительно официальной Precise-модели |
|---|---:|
| MPZ2012S300AT000 | 0,36% |
| MPZ2012S101AT000 | 0,61% |
| MPZ2012S221AT000 | 0,82% |
| MPZ2012S331AT000 | 1,36% |
| MPZ2012S601AT000 | 2,25% |
| MPZ2012S102AT000 | 2,06% |

Отдельно выполнены 6006 сравнений ngspice с независимым узловым расчётом новых схем; максимальное относительное расхождение менее 10⁻⁹. Это проверка реализации и совпадения с эталонной моделью, а не измерение реального изделия. Нативные проверки Altium от 30.10.2026 описаны ниже. Проверки ATD25 описаны отдельным разделом ниже; Murata — в своей директории.

## Как заменить на официальные модели

1. На [странице TDK Chip Beads](https://product.tdk.com/en/technicalsupport/tvcl/general/beads.html) выберите **Commercial Grade for Power Line → MPZ2012 → Precise Model → SPICE**. Архив: [emc_beads_com_power_mpz2012_spice_p.zip](https://product.tdk.com/system/files/dam/technicalsupport/tvcl/spice_p/emc_beads_com_power_mpz2012_spice_p.zip).
2. Распакуйте шесть файлов `<MPN>_p.mod` в эту папку без изменения содержимого. Они исключены из Git и при переносе репозитория устанавливаются отдельно.
3. В `MY_LIB.xlsx`, лист «Ферриты», для L0001–L0006 задайте `Sim Model Name = <MPN>_p`, `Sim File = Simulation\Ferrites\TDK\<MPN>_p.mod`. Например, для MPZ2012S101AT000 — `MPZ2012S101AT000_p` и `Simulation\Ferrites\TDK\MPZ2012S101AT000_p.mod`.
4. Установите `SimulationModelSource = TDK Corporation`, `SimulationModelType = Precise`; обновите `Sim Description`, указав официальную модель и её условия. Сохраните существующие `Sim Kind = General`, `Sim SubKind = Spice Subcircuit`, `Sim Spice Prefix = X`, `Sim Netlist = @DESIGNATOR %1 %2 @MODEL`, `Sim Port Map = (1:1),(2:2)`. Параметры условий остаются 25 °C, 0 А DC bias, малый сигнал.
5. Сохраните книгу, обновите компонент из DbLib в проекте Altium и проверьте имя подсхемы, доступность файла и netlist. Уже размещённые компоненты могут сохранять прежнюю модель до обновления. Править УГО и сопоставления DbLib не требуется.

Для ATD25 нужен отдельный архив Automotive; подставлять AT000 вместо него нельзя. Собственные `.ckt` можно оставить рядом: активную модель определяют параметры строки компонента.

## Нативные испытания — 30.10.2026

Структура соответствует остальным проверенным компонентам: `Tests/` — входные JSON Spice Tester 0.5, `Results/` — отчёты `.result.json`, исходные NSX, расчётные SDF, сводка `ferrites_results_summary.json` и аудит `native_verification.json`. Симулятор — Altium MixedSim 24.4. Условия — +25 °C, малый сигнал, нулевой постоянный ток смещения.

Тесты подготовлены до запуска. Паспортные проверки используют начальное максимальное сопротивление DC и допустимый модуль импеданса на 100 МГц. DC измеряется при диагностическом токе 1 мА по установившейся точке короткого transient-расчёта с обычной начальной рабочей точкой; это не проверка динамики или токовой зависимости. Численный запас DC — 1 мкОм, импеданса — 0,0001 Ом.

Заводская SPICE-модель и MY_LIB рассчитываются одновременно в независимых ветвях с одинаковым возбуждением. Частотная сетка — 348 точек DEC 100 от 1 МГц до 2,951209 ГГц и отдельная точка ровно 3 ГГц. Амплитуда 1 А служит нормировкой линейного AC-расчёта, а не физическим испытанием большим сигналом. Входные JSON проверяют разность импедансов в точках 1/100/1000 МГц и 3 ГГц; отчёты `*.comparison.json` дополнительно проверяют строгий критерий `|Z_MYLIB−Z_vendor|/|Z_vendor| ≤ 3%` на каждой экспортированной частоте без прореживания. Порог выбран до прогона как критерий сходства моделей, не как производственный допуск. Для трёх контрольных точек JSON абсолютное окно 3,05% задано по ранее рассчитанным заводским данным с небольшим запасом интерполяции; итоговый критерий всей сетки остаётся 3%.

DC-сравнение использует допуск 0,01%, минимум 1 мкОм. Для BLM21PG601SN1/SH1 проверяется паспортное Rdc=0,14 Ом и ожидаемая разность с заводским SPICE −0,03 Ом; для остальных моделей — совпадение DC с заводским SPICE. Это не заменяет отдельную проверку паспортного максимума.

Источник паспортных критериев — локальный `Datasheets/Ferrite_Beads/TDK_MPZ2012_commercial.pdf`, 24.04.2019, страница 1. Для 30 Ом используется диапазон 20…40 Ом, для остальных пяти — ±25%. Заводской эталон — TDK Precise от 08.07.2016, локальные `<MPN>_p.mod`.

Все пять тестов PASS: 6 проверок DCR, 6 паспортных проверок Z, 18 частотных контрольных точек, 12 DC-сравнений и 6 проверок на 3 ГГц. Дополнительно все 2094 комплексных сравнения (6 моделей × 349 частот) PASS. Максимальное расхождение — около 2,25%.

Этот прогон охватывает L0001–L0006. Отдельные модели и проверки L0007–L0012 (ATD25) описаны ниже; AT000 за них не подставлялись.

Проверки подтверждают работу файлов моделей в standalone NSX MixedSim и заявленное сходство с заводским SPICE в указанных условиях. Они не проверяют размещение через DbLib/УГО, насыщение, DC-bias-зависимость, температурную точность, саморазогрев, ресурс и допустимую мощность. Полное совпадение с реальными измерениями не установлено. Кроме описанного исправления двух Rdc, модели сохранены; Excel, DbLib, SchLib и PcbLib не изменены.

Для повтора сравнения нужны оригинальные заводские `.mod` рядом с моделями MY_LIB; они исключены из Git и отдельно не распространяются. В тестах используются относительные пути. Сохранённые NSX и диагностические поля отчётов содержат абсолютные пути машины прогона.

## Автомобильные ATD25 — отдельные модели и испытания 30.10.2026

Для L0007–L0012 созданы шесть собственных `MPZ2012S…ATD25_MYLIB.ckt`. Модели привязаны к L0007–L0012 в листе «Ферриты» MY_LIB.xlsx через существующие сопоставления DbLib. Заданы восемь полей Sim и пять полей происхождения/условий; путь Simulation\Ferrites\TDK\<MPN>_MYLIB.ckt относительный, выводы (1:1),(2:2). Заводской источник — отдельный архив TDK `emc_beads_auto_power_mpz2012_spice_p.zip`, Precise Model от 08.07.2016, полученный от пользователя после отказа сервера TDK при скачивании. Проверены точные номера ATD25 и контрольные суммы архива/файлов; коммерческие AT000 не подставлялись. Официальная страница: [TDK Chip Beads](https://product.tdk.com/en/technicalsupport/tvcl/general/beads.html), Automotive Grade for Power Line → MPZ2012 → Precise Model.

Даташит — локальный `Datasheets/Ferrite_Beads/TDK_MPZ2012_automotive.pdf`, 23.04.2019, стр. 1–2. Паспортные пределы: 30 Ом ±10 Ом, остальные 100/220/330/600/1000 Ом ±25% на 100 МГц; DCR max соответственно 0,010/0,020/0,040/0,050/0,100/0,150 Ом. Рабочий температурный диапазон −55…+125 °C не является подтверждением температурной точности моделей.

Сначала выполнены четыре нативных теста оригиналов: паспортный DC, AC DEC100, точка 3 ГГц и отдельная контрольная AC-сетка DEC137. Все 24 контрольные проверки оригиналов PASS. Субагент получил только даташит, условия, измеренное DC и численные комплексные импедансы первой сетки с точкой 3 ГГц (349 частот на исполнение). Заводские netlist, их внутренние коэффициенты, ранее созданные модели и скрипты подбора ему не передавались. Новые схемы и коэффициенты написаны субагентом с нуля. Это собственная аппроксимация по выходам заводской модели, не заводской SPICE и не работа исключительно по табличным данным даташита.

После завершения авторства подготовлены три JSON-теста новых моделей и выполнен нативный прогон: DC по паспорту и заводскому измерению, AC по паспорту на 100 МГц и по контрольной сетке, отдельная точка 3 ГГц. Критерий комплексного расхождения задан до авторства: `|Z_MYLIB−Z_TDK|/|Z_TDK| ≤ 3%` на каждой частоте. Сетка DEC137 (477 точек) не передавалась автору для подбора; точка 3 ГГц проверяется дополнительно. Все 2868 комплексных сравнений (6 × 478) PASS. Численный допуск DC-сравнения — 0,01%, минимум 1 мкОм; паспортный запас — 1 мкОм. Компонентные окна JSON ±3% модуля эталона дополнены обязательной проверкой комплексного расхождения во всех точках в `*.comparison.json`.

| Компонент | Максимальное комплексное расхождение |
|---|---:|
| MPZ2012S101ATD25 | 0.867553% |
| MPZ2012S102ATD25 | 1.235323% |
| MPZ2012S221ATD25 | 0.640780% |
| MPZ2012S300ATD25 | 0.426523% |
| MPZ2012S331ATD25 | 1.258871% |
| MPZ2012S601ATD25 | 1.009808% |

Все файлы находятся в прежней структуре: `Tests/atd25_*.json`, `Results/atd25_*.result.json`, NSX/SDF, сводки `atd25_reference_summary.json` и `atd25_own_summary.json`, аудит `atd25_native_verification.json`. Заводские `.mod` исключены из Git; для повторения оригинальных испытаний их нужно отдельно получить из указанного архива и поместить рядом с собственными моделями. Тесты новых моделей используют только собственные `.ckt` и сохранённые численные эталоны.

Применимость: +25 °C, малый сигнал, DC-bias 0 А, проверенный частотный интервал 1 МГц–3 ГГц. AC-ток 1 А используется только как нормировка линейного расчёта. DC-измерение при 1 мА не подтверждает поведение при номинальном силовом токе. Не моделируются насыщение, токовая/температурная зависимость, саморазогрев, разброс и разрушение. Проверки подтверждают работу standalone NSX MixedSim и сходство с заводским SPICE, а не измеренную точность реальных деталей или корректность размещения из DbLib.

Дополнительно выполнены 2868 независимых узловых расчётов по фактическим номиналам новых netlist: максимальное относительное отличие от Altium около 1,12×10⁻⁹, все PASS. Аудит — `Results/atd25_independent_nodal_verification.json`.

Привязки ATD25 проверены через ACE и обычное открытие отдельным скрытым Excel 16.0 с CorruptLoad=0, без восстановления. Все 78 ферритов теперь имеют привязанную модель. Изменены только 78 целевых ячеек шести строк; остальные ячейки, стили, формулы, кэши и части XLSX сохранены, ID девяти Excel-таблиц уникальны. DbLib, SchLib и PcbLib сохранены. Аудит — Results/atd25_binding_verification.json.
