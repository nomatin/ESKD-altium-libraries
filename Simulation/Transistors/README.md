# Транзисторы — SPICE-модели MY_LIB

## Состав

Две общие параметрические модели маломощных MOSFET в корпусе SOT-23:

- `MY_LIB_NMOS_DS.ckt` — подсхема `MY_LIB_NMOS_DS`, выводы **1=G, 2=S, 3=D**;
- `MY_LIB_PMOS_DS.ckt` — подсхема `MY_LIB_PMOS_DS`, те же выводы **1=G, 2=S, 3=D**.

Обе модели рассчитаны на несколько приборов: параметры передаются из строки
`MY_LIB.xlsx` через `MY_LIB.DbLib`, отдельный файл на каждый транзистор не
создаётся. Файлы идентичны по топологии; у P-канальной модели зеркальны знак
порогового напряжения и полярность встроенного диода (анод — сток, катод — исток).

## Привязка в базе

Лист «Транзисторы» (в IEC-книге — `IEC Transistors`), таблица
`MY_LIB_Transistors` / `MY_LIB_IEC_Transistors` (`Table10` в DbLib).

| Поле | Значение |
|---|---|
| Sim Model Name | `MY_LIB_NMOS_DS` или `MY_LIB_PMOS_DS` по каналу прибора |
| Sim Kind / SubKind | General / Spice Subcircuit |
| Sim Spice Prefix | `X` |
| Sim Port Map | `(1:1),(2:2),(3:3)` |
| Sim File | `Simulation\Transistors\MY_LIB_NMOS_DS.ckt` или `Simulation\Transistors\MY_LIB_PMOS_DS.ckt` |
| Sim Netlist | `@DESIGNATOR %1 %2 %3 @MODEL PARAMS: VTO=@VT_VTO KP=@VT_KP THETA=@VT_THETA CGS=@VT_CGS CGD=@VT_CGD CDS=@VT_CDS ISbody=@VT_IS Nbody=@VT_N` |

Числовые параметры хранятся отдельными столбцами листа `VT_VTO`, `VT_KP`,
`VT_THETA`, `VT_CGS`, `VT_CGD`, `VT_CDS`, `VT_IS`, `VT_N` и подставляются в
строку нетлиста. Имена столбцов `VT_IS` и `VT_N` не совпадают с именами
параметров подсхемы `ISbody` и `Nbody` — это сделано намеренно, чтобы не
путать их с параметрами диодов `IS`/`N`.

## Методика

Подгонка ведётся по **паспортным пределам**, а не по типовому прибору:

- RDS(on) max при основном и пониженном |VGS| — два уравнения на `KP` и `THETA`;
- применена модель **MOS3** (`LEVEL=3`), потому что отношение двух паспортных
  пределов RDS(on) нельзя воспроизвести MOS1 без большого искусственного
  последовательного сопротивления. `RD`/`RS` остаются нулевыми;
- `GAMMA=0`, `PHI=0.7`: данных по смещению подложки в паспортах нет, поэтому
  эффект подложки отключён, а не выдуман;
- `W=L=1 мкм` — численное тождество (`W/L=1` сохраняет `KP`), а не геометрия прибора;
- ёмкости вынесены явными конденсаторами: `CGS = Ciss − Crss`, `CGD = Crss`,
  `CDS = Coss − Crss` при напряжении и частоте паспортной строки;
- `ISbody`/`Nbody` подобраны по типовому `VSD` (или по `VSD` max, если тип не
  опубликован); встроенный переход модели MOS3 отключён (`IS=1e-30`), чтобы
  диод определялся только элементом `Dbody`.

Все расчёты выполнены в ngspice при `.options TEMP=25` — температура строк
Electrical Characteristics паспортов (`TA = 25 °C`).

−1,2 … −0,6 В у BSS215P. Это не перестановка границ, а запись паспортных
столбцов.

## Что не моделируется

- выходная проводимость в насыщении: паспорт её не задаёт, а MOS3 в этом
  диалекте не принимает `LAMBDA` — канал идеален в насыщении;
- температурная зависимость, саморазогрев, ограничение мощности и тока;
- заряд затвора, Qrr, лавина, ESD, разброс экземпляров;
- эффект подложки (`GAMMA=0`);
- разброс и допуски: параметры соответствуют паспортным пределам, а не
  измеренному экземпляру.

Модель описывает поведение в пределах паспортных условий и **не является**
измеренной характеристикой конкретного экземпляра. Заводские SPICE-описания
Infineon использовались только как внешнее контрольное сравнение; их текст в
библиотеку не переносился.

## Посадочное место и УГО

УГО `MOSFET_N_1G2S3D` и `MOSFET_P_1G2S3D` и футпринт `SOT23-3` переиспользованы.
Футпринт: три площадки 0,60 × 1,00 мм, шаг 1,90 мм, ряды площадок на X = ±1,15 мм,
вывод 1 — снизу слева. Шаг совпадает с паспортным (1,90 мм), но размер площадок
и смещение рядов отличаются от рекомендаций Infineon (0,9 × 0,8 мм либо
0,8 × 0,9 мм для BSS84P; 0,972 × 0,802 мм для Micro3). Это ограничение
существующего футпринта, а не CAD производителя. Встроенный STEP типовой.
Нативное отображение УГО, футпринта и 3D в Altium не проверялось.

## Добавление нового транзистора

1. Взять официальный даташит точной редакции и зафиксировать SHA-256.
2. Определить распиновку и подобрать УГО семейства с совпадающими номерами.
3. Проверить футпринт по размерам корпуса.
4. Решить систему по двум пределам RDS(on), задать ёмкости из Ciss/Coss/Crss,
   подобрать `ISbody` по VSD.
5. Добавить строку в лист «Транзисторы» обеих книг, заполнить `VT_*`.
6. Прогнать шесть испытаний в ngspice и убедиться, что прочие строки книг не
   изменились.
