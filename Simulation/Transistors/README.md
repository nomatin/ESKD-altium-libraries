# Транзисторы — SPICE-модели MY_LIB

## Состав

Одна общая параметрическая модель N-канального MOSFET:

- `MY_LIB_NMOS_DS.ckt` — подсхема `MY_LIB_NMOS_DS`, выводы **1=G, 2=S, 3=D**.

Модель рассчитана на несколько компонентов: параметры передаются из строки `MY_LIB.xlsx`
через `MY_LIB.DbLib`, отдельный файл на каждый транзистор не создаётся.

## Привязка в базе

Лист «Транзисторы», таблица `MY_LIB_Transistors` (`Table10` в DbLib).

| Поле | Значение для 2N7002 |
|---|---|
| Sim Model Name | `MY_LIB_NMOS_DS` |
| Sim Kind / SubKind | General / Spice Subcircuit |
| Sim Netlist | `@DESIGNATOR %1 %2 %3 @MODEL PARAMS: VTO=@VT_VTO KP=@VT_KP THETA=@VT_THETA CGS=@VT_CGS CGD=@VT_CGD CDS=@VT_CDS ISbody=@VT_IS Nbody=@VT_N` |
| Sim Spice Prefix | `X` |
| Sim Port Map | `(1:1),(2:2),(3:3)` |
| Sim File | `Simulation\Transistors\MY_LIB_NMOS_DS.ckt` |

Числовые параметры `VT_*` хранятся отдельными столбцами листа и передаются в модель
строкой нетлиста, как это сделано для светодиодов.

## 2N7002 (UMW / Youtai Semiconductor)

Источник: официальный даташит `www.umw-ic.com`, редакция **May.2025**, 6 страниц.
Локальная копия — `Datasheets/Transistors/UMW_2N7002.pdf`.

Важно: в обращении находятся **две разные редакции** этого даташита. Более старая
(доступна через дистрибьюторов) указывает ID = 0,115 А и RDS(on) 5/7 Ом. Текущая
официальная редакция даёт ID = 300 мА и RDS(on) < 3/4 Ом. Для модели взята текущая.
Страница товара на сайте производителя указывает «1.15 A» — это опечатка сайта.

### Метод подгонки

Выбраны паспортные **пределы**, а не типичный прибор: RDS(on) ≤ 3 Ом при VGS=10 В
(ID=300 мА) и ≤ 4 Ом при VGS=5 В (ID=150 мА). Отношение этих пределов нельзя
воспроизвести моделью MOS1 без большого искусственного последовательного
сопротивления, поэтому применена **MOS3** с деградацией подвижности (`THETA`).
Подгонка решена численно с учётом квадратичного члена линейного режима.

| Параметр | Значение | Происхождение |
|---|---|---|
| `VTO` | 2,0 В | выбран внутри паспортного окна 1…2,5 В |
| `KP` | 0,267974 А/В² | решение системы по двум пределам RDS(on) |
| `THETA` | 0,609869 1/В | решение системы по двум пределам RDS(on) |
| `RD`, `RS` | 0 | паспорт не требует последовательного сопротивления |
| `CGS` | 45 пФ | Ciss − Crss |
| `CGD` | 5 пФ | Crss |
| `CDS` | 20 пФ | Coss − Crss |
| `ISbody` | 4,2e-15 А | подгонка VSD ≈ 0,77 В при 115 мА |
| `Nbody` | 1 | принято |

Ёмкости вынесены в явные конденсаторы, а не берутся из встроенной ёмкости затвора:
так значения остаются читаемыми и не зависят от `W`/`L`, которые в модели равны
1 мкм и являются численным тождеством, а не геометрией прибора.

### Результаты проверки

Расчёты выполнены в ngspice 44 (библиотека из KiCad 9), исходные данные — из даташита,
а не из модели. 9 из 9 проверок PASS при +25 °C:

| Проверка | Результат | Предел |
|---|---|---|
| RDS(on) @ VGS=10 В, 300 мА | 2,900 Ом | ≤ 3 Ом |
| RDS(on) @ VGS=5 В, 150 мА | 3,900 Ом | ≤ 4 Ом |
| VGS(th) @ 250 мкА | 2,044 В | 1…2,5 В |
| gm @ VDS=10 В, 200 мА | 168,6 мСм | ≥ 80 мСм |
| Ciss / Coss / Crss @ 25 В, 1 МГц | 50 / 25 / 5 пФ | 50 / 25 / 5 пФ |
| VSD @ 115 мА | 0,769 В | 0,55…1,2 В |
| IDSS @ 60 В | 0,12 нА | ≤ 80 нА |

Отдельно проверено, что модель не меняет посторонние листы книги и что ACE и
штатный Excel читают строку без восстановления файла.

### Что не моделируется

- выходная проводимость в насыщении (даташит её не задаёт, а MOS3 в этом диалекте
  не принимает `LAMBDA` — канал идеален в насыщении);
- температурная зависимость, саморазогрев, ограничение мощности и тока;
- заряд затвора, Qrr, лавина, ESD, разброс экземпляров;
- эффект подложки (`GAMMA=0`) — данных по смещению подложки в даташите нет.

Модель описывает поведение в пределах паспортных условий и **не является**
измеренной характеристикой конкретного экземпляра.

## Проверка 3D и посадочного места

`SOT23-3` и УГО `MOSFET_N_1G2S3D` переиспользованы из библиотеки без изменений.
Встроенный STEP типовой: контрольные суммы Altium совпадают, поворот `ROTZ=-90°`
согласован с площадками, но высота модели (~1,3 мм) превышает паспортный предел
1,15 мм. Это ограничение существующего футпринта, а не CAD производителя.

## Добавление нового транзистора

1. Взять официальный даташит точной редакции, зафиксировать SHA-256.
2. Определить распиновку и подобрать УГО `MOSFET_N_1x2y3z` с совпадающими номерами.
3. Подобрать или проверить футпринт по размерам корпуса.
4. Решить систему по двум пределам RDS(on) (см. выше), задать ёмкости из Ciss/Coss/Crss.
5. Добавить строку в лист «Транзисторы», продублировать Numeric-параметры `VT_*`.
6. Прогнать проверки по даташиту в ngspice и убедиться, что остальные строки книги не изменились.

Файлы прогона 2N7002 (скрипты подгонки, проверок, превью) хранятся в
`work/component_pipeline/run-20261101-2n7002/` и в Git библиотеки не входят.
