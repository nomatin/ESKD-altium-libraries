# Универсальная SPICE-модель кварцевого резонатора

`MY_LIB_XTAL_BVD` описывает малосигнальный отклик на основной моде по схеме Баттерворта — Ван Дайка. В ЕСКД и IEC экземпляр получает параметры из строки каталога.

| Параметр модели | Поле каталога ZQ0001 | Значение ZQ0001 |
|---|---|---:|
| `FnomMHz` | `FrequencyMHz` | 8 МГц |
| `CLpF` | `LoadCapacitancePf` | 12 пФ |
| `RmOhm` | `ESRMaxOhm` | 150 Ом, паспортный максимум |
| `C0pF` | `ShuntCapacitanceMaxPf` | 2 пФ, паспортный максимум |
| `CmfF` | `MotionalCapacitanceFf` | 5 фФ, расчётное допущение |

Точное исполнение YXC B.0 не задаёт C1. Для ZQ0001 в качестве расчётного значения взят максимум 5 фФ из спецификации родственного `X32258MOB4SI`. Типовые параметры экземпляра и разброс по этим данным не определяются. Для следующего кварца задавайте все пять параметров его строки. Допущения указывайте рядом с записью. [Паспорт XL2OI-111-8M](../../Datasheets/YXC/XL2OI-111-8M.pdf), [паспорт родственного артикула](https://datasheet.lcsc.com/lcsc/2403291505_YXC-X32258MOB4SI_C2682775.pdf).

Выводы 1 и 3 — электроды, 2 и 4 — выводы корпуса. Порядок портов 1–2–3–4. Электрические связи корпуса опущены в эквивалентной схеме. На реальной плате выводы корпуса подключают по паспорту.

Модель вычисляет Lm для верхнего нуля susceptance при номинальной частоте под внешней CL с учётом Rm. CL задаёт условие калибровки. Для расчёта с этой нагрузкой подключите её между 1 и 3 или реализуйте эквивалентную внешнюю сеть. Для параметров нужны положительные Fnom, Rm, C0 и Cm, неотрицательная CL и условие `2·ω₀·(C0+CL)·Rm < 1`. Модель применима вблизи основной моды при малом сигнале. Температурная кривая, старение, начальный разброс, паразитная связь с корпусом, побочные моды, зависимость от мощности возбуждения и запуск генератора не моделируются.

## Проверка

В `tests/` — диагностические расчёты ngspice из KiCad 9. Запуск `python tests/validate.py` из каталога модели. Проверены резонанс с нагрузкой, ESR, смещение резонанса при смене нагрузки, симметрия, отсутствие ветвей корпуса и переопределение пяти параметров на синтетическом примере. MixedSim 24.4.1 через Spice Sifter прошёл две автономные AC-проверки ZQ0001. При 8 МГц и внешней нагрузке 12 пФ импеданс составил 13,310 кОм с практически нулевой мнимой частью. После предварительной загрузки записи через двухвыводный режим Spice Sifter оба многовыводных теста DbLib Component прошли. В каждом NSX подтверждены все четыре порта и пять значений из каталога. В DC-тесте обе базы дали 0,100 В на разомкнутом для постоянного тока резонаторе. Частотный отклик проверялся отдельным автономным AC-тестом MixedSim.

## Расчётные параметры серии XL2OI-111

Все 25 каталожных позиций используют общую модель. Для ZQ0001 (8 МГц) сохранён ранее проверенный сценарий с C0 = 2 пФ. Для ZQ0002–ZQ0025 задано C0 = 3 пФ по [общей спецификации YSX321SL](https://datasheet.lcsc.com/datasheet/pdf/a84bd8d530dd46e4b0f6d0ee59d8a89c.pdf). ESR берётся из текущей строки каталога и для новых позиций соответствует пределам использованной при регистрации редакции паспорта серии. Номинальная частота и CL передаются из строки компонента.

C1 = 5 фФ — расчётное допущение по паспортным пределам родственных [X32258MOB4SI](https://datasheet.lcsc.com/lcsc/2403291505_YXC-X32258MOB4SI_C2682775.pdf) и [X322527MSB4SI](https://taoic.oss-cn-hangzhou.aliyuncs.com/5375/product/13928452225_1685589638000.pdf). Оно не характеризует разброс C1 и не является паспортным значением для XL2OI-111. Без измерений оно не подтверждает точность перестройки частоты нагрузкой, добротность и запуск генератора.
