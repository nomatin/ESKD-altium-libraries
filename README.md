# MY_LIB — ручная библиотека Altium Designer 24 DbLib

Основной источник данных — `MY_LIB.xlsx`. На листах «Резисторы», «Конденсаторы» и «Микросхемы» после удаления начальных незаполненных заготовок осталось соответственно 292, 276 и 4 позиции. Дополнительно ведутся листы «Разъёмы», «Переключатели», «Светодиоды» и «Тестовые точки». Общего листа Components нет. Одна строка соответствует одной позиции библиотеки; заголовки находятся в первой строке. У оставшихся резисторов, конденсаторов и микросхем заполнены MPN и ссылки на УГО и посадочные места. Все листы включены в DbLib.

## Структура папок

```text
MY_LIB/
  MY_LIB.xlsx           параметры и редактируемые формулы
  MY_LIB.DbLib          подключение Altium к Excel
  ALTIUM_SETUP.md     пошаговое подключение и проверка
  README.md           правила работы
  Symbols/            файлы .SchLib
  Footprints/         файлы .PcbLib
  Datasheets/         документация выбранных компонентов
  Backup/             ручные резервные копии
```

Файл `MY_LIB.DbLib` находится рядом с Excel. Выбран установленный 64-разрядный провайдер Microsoft.ACE.OLEDB.12.0; чтение Excel через него проверено. В подключении сохранён абсолютный путь к текущему MY_LIB.xlsx, а пути к моделям в Excel заданы относительно папки DbLib. При переносе папки заново выберите Excel в настройках DbLib.

## Листы и поля таблиц

На всех трёх листах сохранены исходные поля A:S. На листе «Микросхемы» дополнительно заполнены поля T:AD: температуры, даташиты и ссылки документов Altium. На листе «Конденсаторы» порядок основных параметров: C — Value, D — ESKD_value, E — Tolerance, F — Power, G — Voltage, H — Dielectric, I — Package. Далее J — Manufacturer, K — MPN, L — CommentBase, M:P — ссылки на модели, Q — Notes. На остальных листах порядок прежний. Добавляйте новые типы отдельными листами с собственными таблицами и отдельным буквенным префиксом ID. Новых категорий без компонентов пока не добавлено.

| Поле | Назначение |
|---|---|
| ID | Постоянный уникальный ключ: R0001, C0001, U0001. Не обозначение на схеме. |
| Type | Русское родовое название: Резистор, Конденсатор, Микросхема. |
| Value | Исходное текстовое значение в оговорённой инженерной записи. |
| ESKD_value | Формула читаемого номинала, например 10 кОм. |
| Tolerance | Текст с символом допуска, например ±1%. |
| Power | Текст с единицей, например 0,125 Вт. |
| Voltage | Текст с единицей, например 50 В. |
| Package | Корпус: 0805, 0603, SOIC-8. Коды резисторов и конденсаторов в примерах — дюймовые. Это не имя footprint. |
| Manufacturer | Производитель, если выбран. |
| MPN | Отдельный артикул производителя; для типовой позиции может быть пустым. |
| CommentBase | Редактируемая формула полного наименования для Description и перечня элементов. |
| Library Ref | Точное имя символа внутри SchLib. |
| Library Path | Путь к файлу SchLib. |
| Footprint Ref | Точное имя посадочного места внутри PcbLib. |
| Footprint Path | Путь к файлу PcbLib. |
| Notes | Короткие замечания и исключения. |
| Dielectric | Диэлектрик/температурная характеристика конденсатора, например X7R или C0G. На листе «Конденсаторы» находится в H между Voltage и Package; на других листах — в Q. |

Зелёные ячейки — формулы. Жёлтые формулы — примеры индивидуального правила: K6 листа «Резисторы» и K2 листа «Микросхемы». Светло-жёлтые поля ссылок на модели: M:P у конденсаторов и L:O на остальных листах. Для R/C и U0002/U0003 они заполнены; у заготовки U0001 оставлены пустыми. Остальные поля редактируются вручную. Параметры с единицами обычно хранятся как текст для DbLib. Новые минимальные и максимальные температуры микросхем записаны числами в °C; тип температуры указан отдельно.

## Правила ведения

1. ID назначайте вручную: префикс категории и четыре цифры. R — резистор, C — конденсатор, U — микросхема. Например, следующему резистору присвойте R0009. Не используйте номер строки как ID, не переименовывайте ID при сортировке и не выдавайте удалённые ID заново.
2. Для новой позиции откройте лист нужного типа и копируйте всю строку той же категории, включая формулы ESKD_value и CommentBase, затем изменяйте ID и параметры. После вставки проверяйте ссылки формул. Разные корпуса, мощность, допуск или другие существенные требования — разные позиции, даже при одинаковом Value.
3. Вводите Value текстом. В C используйте точку в дробной части и латинские суффиксы. В результирующем D точка заменяется запятой.
4. Наименование обычного резистора собирайте через номинал, допуск и корпус. Мощность остаётся отдельным обязательным требованием в Power. Для конденсатора используйте номинал, допуск, напряжение, диэлектрик/ТКЕ и корпус. MPN взаимозаменяемых компонентов храните отдельно и не включайте в CommentBase, даже если он заполнен. Отсутствие MPN в названии само по себе не доказывает взаимозаменяемость: проверяйте корпус и необходимые параметры, включая мощность, напряжение, ТКС и особенности применения. Дополнительные требования можно пока записывать в Notes.
5. Формулы ESKD_value и CommentBase доступны для ручного изменения в любой строке. Для особого компонента копируйте подходящую строку и меняйте формулу. Excel может предложить распространить формулу на весь столбец таблицы: отклоните распространение, если правка касается одной строки.
6. Перед массовой правкой сохраните копию в Backup. Сортируйте всю таблицу, а не отдельный столбец. Пустые строки в конце не добавляйте заранее. При добавлении строки расширьте таблицу, если Excel не сделал этого автоматически.
7. Имена полей и листа не меняйте после настройки DbLib без обновления сопоставлений. Не используйте объединённые ячейки, заголовки над таблицей и разные типы данных в одном столбце.

## Простые формулы

Внутри XLSX формулы записаны с английскими именами функций и запятыми-разделителями. Русский Excel может показывать локализованные имена и разделители `;`.

Для резистора в строке 2 листа «Резисторы»:

```excel
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(C2,"meg"," МОм"),"k"," кОм"),"R"," Ом"),".",",")
```

В русском Excel эквивалент:

```excel
=ПОДСТАВИТЬ(ПОДСТАВИТЬ(ПОДСТАВИТЬ(ПОДСТАВИТЬ(C2;"meg";" МОм");"k";" кОм");"R";" Ом");".";",")
```

Наименование обычного резистора по принятому сокращённому правилу:

```excel
=B2&" "&D2&" "&E2&" "&H2
```

Результат: **Резистор 10 кОм ±1% 0805**. Для R0007: **Резистор 0,1 Ом ±1% 1206**. Корпус берётся из Package, слово «корпус» в результат не добавляется. Мощность хранится в Power и не выводится в это сокращённое наименование. MPN в формуле отсутствует. Скобок в результирующем наименовании нет; скобки в синтаксисе функций Excel необходимы.

Для перемычки R0005 в строке 6 допуск пропущен отдельной простой формулой:

```excel
=B6&" "&D6&" "&H6
```

Для конденсатора в строке 2 листа «Конденсаторы»:

```excel
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(C2,"p"," пФ"),"n"," нФ"),"u"," мкФ"),".",",")
=B2&" "&D2&" "&E2&" "&G2&" "&H2&" "&I2
```

Результат: **Конденсатор 100 нФ ±10% 50 В X7R 0603**. На листе «Конденсаторы» D2 — ESKD_value, H2 — Dielectric, I2 — Package, L2 — CommentBase. X7R в двух начальных примерах задаёт требование к выбору компонента, а не подтверждённую характеристику конкретного MPN. Для полярного конденсатора или другой индивидуальной строки можно убрать ссылку на H из формулы на листе «Конденсаторы», если она неприменима. MPN в формулу конденсаторов не входит.

Для уникального компонента U0001 в строке 2 листа «Микросхемы»:

```excel
=C2
=B2&" "&J2
```

Здесь первая формула — D2, вторая — K2 листа «Микросхемы». Пример результата: **Микросхема LM358DR**. При необходимости название можно расширить простым сцеплением полей. MPN для этого варианта должен быть заполнен.

## Пределы преобразования Value

| Категория | Поддерживаемая запись | Результат |
|---|---|---|
| R | 100R, 0R, 0.1R | 100 Ом, 0 Ом, 0,1 Ом |
| R | 10k, 4.7k | 10 кОм, 4,7 кОм |
| R | 1meg, 2.2meg | 1 МОм, 2,2 МОм |
| C | 22p, 100n, 4.7u | 22 пФ, 100 нФ, 4,7 мкФ |
| U | Произвольный тип, например LM358 | Без преобразования |

Это буквальные замены, а не универсальный парсер SPICE и не пересчёт единиц. Для сопротивления в омах обязательно добавляйте R. Число 100 без R не получит единицу. Записи 4R7, 4k7, 10K, 1M, 1Meg, 1e3, суффиксы m/G и символ µ не поддерживаются. Неправильная запись может остаться текстом без ошибки Excel. Используйте ровно регистр и суффиксы из таблицы. `meg` выбран явно: M/m в SPICE могут означать милли, а не мега.

Пустые обязательные поля в формулах CommentBase не отфильтровываются и могут давать лишние пробелы. Заполните поля либо упростите формулу конкретной строки, как у R0005. Для другой категории скопируйте понятное правило или напишите отдельную формулу. Формулы не проверяют соответствие ЕСКД автоматически. CommentBase задаёт принятую здесь структуру наименования; для конкретного проекта уточняйте требования к перечню элементов.

Конденсаторы приведены только как примеры структуры: перед применением подтвердите заданный диэлектрик X7R и другие необходимые требования. Микросхема — пример связи MPN с наименованием. Для R/C модели привязаны по корпусу. Проверены имена моделей и номера выводов; размещение и передачу на плату нужно проверить в Altium. У заготовки U0001 LM358 пока нет готового УГО. У U0002/U0003 модели заполнены.

## Применение приложенных правил наименования

Основание: «Правила составления наименований перечня элементов», РД УР.016-24, издание 2024 г., АО «УРАНИС-РАДИОСИСТЕМЫ». Использованы п. 3.1, 4.1, 4.5.1–4.5.2 и 4.8, страницы 4–5, 11–12 и 20.

Общая форма документа: тип, электрические параметры, корпус, дополнительные параметры. Для взаимозаменяемых компонентов используется общее параметрическое наименование. Код производителя нужен для отдельных компонентов с ограничением замены; он не добавляется автоматически ко всем строкам.

В текущей таблице действует уточнение владельца библиотеки: для резисторов CommentBase содержит только тип, номинал, допуск и корпус. Это сокращение относительно п. 4.8, где предусмотрена также мощность. Power сохраняется отдельно и учитывается при выборе и замене. При необходимости вернуть полную форму документа замените формулу нужной строки на:

```excel
=B2&" "&D2&" "&E2&" "&F2&" "&H2
```

Скобки в результирующие наименования не добавляются по принятому правилу библиотеки. Формулы редактируются по строкам. Правила остальных категорий из PDF не автоматизированы, а пример микросхемы оставлен без изменений.

## Документация

[Создание и настройка DbLib](https://www.altium.com/documentation/altium-designer/components-libraries/database-libraries/creating-defining).

[Установка и поиск компонентов](https://www.altium.com/documentation/altium-designer/schematic/components-file-based-database-libraries).

Сопоставление полей в DbLib: Comment → Comment (номинал на схеме), Description → [Description] (полное наименование). ESKD_value → ESKD_value и CommentBase → CommentBase сохраняют исходные параметры в свойствах компонента. CommentBase находится в K у резисторов/микросхем и в L у конденсаторов.

Столбцы R (Comment) и S (Description) содержат формулы =D2 и =K2 у резисторов/микросхем, =D2 и =L2 у конденсаторов (номер строки меняется). Все исходные поля A:Q сохранены. Для новой строки R/C копируйте A:S, для микросхем — A:AD. В Altium CommentBase и остальные пользовательские параметры находятся в Properties → Parameters; Description — системное описание.
