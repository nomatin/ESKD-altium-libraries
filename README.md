# MY_LIB — библиотека компонентов для Altium Designer

Персональная библиотека УГО, посадочных мест и параметров электронных компонентов для Altium Designer 24. Данные компонентов хранятся в Excel и подключаются к Altium через DbLib. УГО оформлены по принятым в проекте правилам с использованием шрифта Altium GOST Type A.

**Коммерческое использование авторских материалов запрещено условиями CC BY-NC 4.0.** См. [лицензию](LICENSE) и [условия для сторонних материалов](THIRD_PARTY_NOTICES.md).

## Состав библиотеки

Состояние базы на 27 октября 2026 года: **960 позиций**.

| Категория | Позиций | Содержание |
|---|---:|---|
| Резисторы | 582 | YAGEO RC, в том числе E24 с допусками ±1% и ±5%, перемычки 0 Ом |
| Конденсаторы | 276 | Керамические конденсаторы YAGEO |
| Микросхемы | 4 | CP2102N-A02-GQFN24, USBLC6-2SC6, ISOW1432DFMR, CDSOT23-SM712 |
| Разъёмы | 2 | GCT USB4110-GF-A, CONNFLY DS1037-01-09F |
| Переключатели | 1 | CONNFLY DS1040-01RT |
| Светодиоды | 14 | Oasistek TO-1608BC и TO-2013BC |

В SchLib также есть универсальные УГО разъёмов `X_1`–`X_40` и полупроводников: диодов, стабилитрона, светодиода, NPN/PNP и MOSFET N/P. Наличие УГО в SchLib не означает наличия готовой строки компонента в базе или привязки к конкретному корпусу.

## Подключение

Для работы через DbLib нужны Altium Designer 24, Microsoft Excel для пересчёта книги и совместимый с разрядностью Altium провайдер Microsoft ACE OLE DB. В текущем DbLib используется `Microsoft.ACE.OLEDB.12.0`.

1. Сохраните структуру папок: `MY_LIB.DbLib` и `MY_LIB.xlsx` должны лежать рядом с `Symbols/` и `Footprints/`.
2. Установите шрифт **Altium GOST Type A**, если его нет в системе.
3. Откройте `MY_LIB.xlsx` в Excel, выполните полный пересчёт **Ctrl+Alt+F9**, сохраните и закройте книгу. Altium читает сохранённые результаты формул.
4. Откройте `MY_LIB.DbLib` в Altium. В строке подключения замените `Data Source` на фактический путь к `MY_LIB.xlsx`: в файле пока сохранён абсолютный путь компьютера автора. Подключитесь к базе.
5. Установите `MY_LIB.DbLib` через **Preferences → Data Management → File-based Libraries → Installed → Install from file**.
6. В панели **Components** выберите нужную таблицу библиотеки и компонент по его постоянному `ID`.
7. Перед использованием в проекте проверьте размещение на тестовой схеме, выбранное посадочное место и соответствие выводов при передаче на плату.

Подробности настройки и устранения ошибок: [ALTIUM_SETUP.md](ALTIUM_SETUP.md). Документ содержит также историю настройки; старые примеры с удалёнными ID и прежним количеством позиций не описывают текущую базу. Актуальные компоненты и ссылки смотрите в `MY_LIB.xlsx`.

## Работа с базой

### Даташиты

У компонентов, кроме контрольных точек, `Datasheet` и `HelpURL` указывают на локальный PDF в `Datasheets/`. В меню **References** размещённого компонента доступны две ссылки: **Даташит — локальный** (`ComponentLink1URL`) и **Даташит — производитель** (`ComponentLink2URL`). Для открытия основного локального документа используется также F1 над компонентом.

Ссылки передаются из Excel через DbLib. Для уже размещённых компонентов требуется обновление параметров из базы. Локальные пути абсолютные: при переносе библиотеки на другой компьютер измените префикс пути в столбцах `Datasheet`, `HelpURL` и `ComponentLink1URL`.

Для резисторов и конденсаторов используются общие документы серий YAGEO RC_L и CC X7R. Для светодиодов без отдельного PDF указан каталог Oasistek. У контрольных точек поля документации пустые и не сопоставлены в DbLib.

Одна строка Excel соответствует одному компоненту. Структура полей зависит от категории; копируйте всю строку того же листа вместе с формулами и дополнительными параметрами.

| Поле | Назначение |
|---|---|
| `ID` | Постоянный уникальный ключ компонента |
| `Type`, `Value`, `ESKD_value` | Тип, исходный номинал и его читаемая запись |
| `Tolerance`, `Power`, `Voltage`, `Dielectric` | Требования и электрические параметры, где применимо |
| `Package` | Обозначение корпуса; не имя посадочного места |
| `Manufacturer`, `MPN` | Производитель и артикул |
| `CommentBase` | Формула полного наименования |
| `Comment`, `Description` | Значения для соответствующих полей Altium |
| `Library Ref`, `Library Path` | Имя УГО и путь к SchLib |
| `Footprint Ref`, `Footprint Path` | Имя посадочного места и путь к PcbLib |
| `Notes` | Ограничения, замечания и неподтверждённые данные |

- Назначайте новый `ID` вручную с префиксом своей категории. Не меняйте ID при сортировке и не используйте повторно удалённые идентификаторы.
- Разные корпуса, допуски и другие существенные требования оформляйте отдельными позициями.
- Имена листов и столбцов связаны с настройками DbLib. При их изменении обновляйте сопоставления.
- Пути к SchLib и PcbLib в таблице задаются относительно папки DbLib. Имена моделей должны точно совпадать с именами внутри библиотек.
- Формулы `ESKD_value` и `CommentBase` можно менять для отдельной строки. Проверяйте, что Excel не распространил индивидуальную формулу на весь столбец.
- После изменений пересчитывайте книгу в Excel, сохраняйте её и обновляйте подключение в Altium. Для уже размещённых компонентов просматривайте изменения при обновлении параметров из базы.

Для номиналов используются записи `100R`, `4.7k`, `1meg`, `22p`, `100n`, `4.7u`. Формулы выполняют буквальные замены; записи вроде `4R7`, `10K` или `1M` требуют отдельной обработки.

## Оформление УГО

- `Designator` и `Comment`: чёрный цвет, **Altium GOST Type A, 10, курсив**. Видимость, положение и поворот сохраняются по настройкам конкретного УГО.
- Микросхемы: белое прямоугольное тело, чёрный контур и разделители, функциональные группы; обычная длина и шаг выводов — 100 mil. Одностороннее расположение выводов допустимо.
- Универсальные разъёмы: табличные поля «Конт.» / «Цепь», редактируемые параметры `PinN_Name`; линии, выводы и надписи чёрные.
- Общие полупроводниковые УГО расположены горизонтально; управляющие выводы B/G направлены вниз. Их геометрия имеет отдельные правила.
- Ручные правки библиотек сохраняются. Старые генераторы не следует запускать поверх текущих файлов без анализа изменений.

## Проверки и ограничения

### Ферритовые фильтры MPZ2012S и BLM21PG

В `Footprints/MY_LIB_Inductors.PcbLib` добавлены `TDK_MPZ2012S_2012` и `Murata_BLM21PG_2012_Reflow`. Площадки созданы по даташитам: соответственно 0,80 × 1,20 мм с зазором 1,00 мм и 0,60 × 1,25 мм с зазором 1,20 мм (Murata — монтаж оплавлением). Выводы 1 и 2 расположены слева и справа; компоненты неполярные.

Динамический `.Designator` расположен над компонентом на Top Overlay. Площадки формируют Top Layer, Top Solder (расширение 0,05 мм) и Top Paste (без уменьшения). Шелкография толщиной 0,12 мм отстоит от окон маски минимум на 0,215 мм. Mechanical 13 / Top Assembly содержит максимальный контур корпуса, Mechanical 15 / Top Courtyard — замкнутую границу размещения с запасом не менее 0,25 мм от меди и проекции модели; Mechanical 1 / 3D Body используется для встроенной модели. При переносе в плату проверяйте соответствие механических слоёв её принятому назначению.

STEP получены через Ultra Librarian для MPZ2012S300AT000 и BLM21PG221SN1D и встроены без изменения геометрии; отдельные файлы находятся в `3D/Ferrite_Beads/`, исходные архивы — в `Footprints/Ferrite_Beads/Original/`. Модель TDK имеет высоту 1,10 мм вместо максимальных 1,05 мм в даташите; Height футпринта принят 1,10 мм, чтобы учитывать фактически встроенную модель при проверке зазоров. Для Murata Height равен 1,05 мм. Модели представляют близкие к максимальным, а не номинальные размеры корпусов. Оба новых посадочных места проверены в 2D и с отображением встроенных STEP в Altium Designer 24.4.1.

Документация: [TDK MPZ2012, стр. 3](https://product.tdk.com/system/files/dam/doc/product/emc/emc/beads/catalog/beads_commercial_power_mpz2012_en.pdf), [Murata ENFA0005, раздел 12.1](https://www.murata.com/products/productdata/8796738977822/ENFA0005.pdf). Для BLM21PG необходимо отдельно соблюдать указанную Murata ширину подводящей меди в зависимости от конкретного артикула, тока и толщины меди.

В Excel/DbLib подключён раздел **«Ферриты»**, 78 артикулов с УГО `Ferrite_Bead` и указанными посадочными местами:

- TDK MPZ2012S: шесть номиналов 30 / 100 / 220 / 330 / 600 / 1000 Ом при 100 МГц в исполнениях `AT000` и `ATD25` (AEC-Q200), всего 12 артикулов. Параметры — по [коммерческому](https://product.tdk.com/en/system/files/dam/doc/product/emc/emc/beads/catalog/beads_commercial_power_mpz2012_en.pdf) и [автомобильному](https://product.tdk.com/en/system/files/dam/doc/product/emc/emc/beads/catalog/beads_automotive_power_mpz2012_en.pdf) даташитам.
- Murata BLM21PG: восемь номиналов 22 / 30 / 60 / 120 / 220 / 330 / 600 / 1000 Ом в исполнениях `SN1` и `SH1`, шесть номиналов 22–330 Ом в `SZ1`. Для каждого предусмотрены коды упаковки `D` (бумажная лента, катушка 180 мм, 4000 шт.), `J` (330 мм, 10000 шт.) и `B` (пакет, 1000 шт.), всего 66 артикулов. Источники: [ENFA0005](https://www.murata.com/products/productdata/8796738977822/ENFA0005.pdf), [QNFA9102](https://www.murata.com/products/productdata/8796740354078/QNFA9102.pdf) и каталог C51E от 07.01.2022, стр. 90–91. `SN1` — обычное исполнение, `SH1` — автомобильное powertrain/safety, `SZ1` — infotainment/comfort.

Поля `ImpedanceOhm`, `TestFrequencyMHz`, `RatedCurrentA`, `RatedCurrent125CA`, `DCResistanceMaxOhm` хранят числовые параметры в единицах, указанных в имени. Для Murata ток задан отдельно при температуре окружающей среды 85 °C и 125 °C; у TDK основной ток относится к температуре компонента до 85 °C с учётом саморазогрева, выше требуется снижение по графику. У TDK 30 Ом допуск ±10 Ом; у Murata 30 Ом — типовое значение (для SN1/SH1 гарантируется минимум 20 Ом), поэтому процентный допуск ему не назначен. DCR — начальное максимальное сопротивление, а не предел после испытаний.

PDF находятся в `Datasheets/Ferrite_Beads/`. `Datasheet`, `HelpURL` и первая ссылка ведут на локальный файл, вторая ссылка — на документ производителя. Файл `Murata_BLM21PG_C51E_excerpt.pdf` содержит неизменённые страницы 90–91 заводского каталога с исходной нумерацией.

У ферритов `Library Path` и `Footprint Path` заданы относительно папки `MY_LIB.DbLib`: `Symbols\MY_LIB_Inductors.SchLib` и `Footprints\MY_LIB_Inductors.PcbLib`. Для привязок моделей внутри библиотеки использовать только относительные пути. После изменения базы закройте в Altium старый DbLib без сохранения и откройте файл с диска заново, чтобы перечитать новый раздел и сопоставления моделей.

Перед выпуском платы сверяйте распиновку, нумерацию площадок, размеры, полярность и электрические параметры с документацией конкретного артикула. Правила оформления библиотеки сами по себе не подтверждают полное соответствие ЕСКД.

Особенности отдельных компонентов:

- У общих полупроводниковых УГО нумерация условная: её нужно согласовать с конкретным компонентом перед назначением корпуса.
- Исходные модели и чертежи отдельных посадочных мест находятся в `Footprints/`. Наличие STEP или успешное чтение файла не заменяет проверку отображения в Altium. Рабочие отчёты агента хранятся локально и не входят в Git.
- Для пяти светодиодов соответствие заводской нумерации не подтверждено; ограничения указаны в полях `Notes` и `PinMapping` базы.

Библиотека предоставляется без гарантий. Проверка конкретного проекта перед изготовлением остаётся ответственностью пользователя.
