# MY_LIB — библиотека компонентов для Altium Designer

Библиотека УГО, посадочных мест, STEP- и SPICE-моделей для **Altium Designer 24**. База компонентов — Excel с подключением через DbLib. Оформление УГО использует шрифт **Altium GOST Type A**.

## Подключение

Нужны Altium Designer 24, Excel и совместимый по разрядности провайдер Microsoft ACE OLE DB.

1. Сохраните структуру папок библиотеки и установите шрифт **Altium GOST Type A**.
2. Откройте `MY_LIB.xlsx`, выполните **Ctrl+Alt+F9**, сохраните и закройте книгу.
3. В `MY_LIB.DbLib` замените `Data Source` на свой путь к книге и установите DbLib через **Preferences → Data Management → File-based Libraries**.
4. Выберите таблицу и компонент в панели **Components**. При переносе библиотеки актуализируйте абсолютные ссылки на локальные даташиты.

Подробная инструкция: [ALTIUM_SETUP.md](ALTIUM_SETUP.md). Пути к УГО, футпринтам и SPICE-моделям заданы относительно DbLib; структуру каталогов сохраняйте.

## SPICE и испытания

Модели привязаны к компонентам через Excel/DbLib. Результаты и ограничения:

| Модели | Проверки |
|---|---|
| [Резисторы](Simulation/Resistors/README.md) | MixedSim: 9312 PASS; температурная зависимость, отдельный параметр `TCR` |
| [Конденсаторы](Simulation/Capacitors/README.md) | MixedSim: 1380 проверок и 552 дополнительных измерения PASS |
| [Диоды](Simulation/Diodes/README.md) | MixedSim: 991 статическая проверка и дополнительные испытания PASS |
| [USBLC6-2SC6](Simulation/USBLC6-2SC6/README.md) / [CDSOT23-SM712](Simulation/CDSOT23-SM712/README.md) | MixedSim: 48 / 22 проверки PASS |
| Ферриты [TDK](Simulation/Ferrites/TDK/README.md) / [Murata](Simulation/Ferrites/Murata/README.md) | ngspice: сравнение с официальными моделями; Altium не проверен |

JSON-тесты и отчёты находятся в `Tests/` и `Results/` рядом с испытанными моделями. **PASS подтверждает конкретные условия теста, а не все характеристики изделия.** Для USBLC6 модель ограничена +27 °C; 10 из 48 проверок — диагностика при +25 °C вне этого ограничения. Тепловая стойкость и соответствие IEC ESD не подтверждаются. Подробности — по ссылкам выше и в [допущениях симуляции](SIMULATION_ASSUMPTIONS.md).

Перед изготовлением платы сверяйте распиновку, посадочное место и ограничения в `Notes` с даташитом конкретного артикула. У универсальных полупроводниковых УГО нумерация условная; у части светодиодов заводская нумерация не подтверждена.
