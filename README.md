# ESKD Altium Libraries

Библиотека компонентов для **Altium Designer 24** с условными графическими обозначениями в стилистике ЕСКД. Содержит посадочные места, STEP/3D-модели и SPICE-модели; компоненты с конкретными артикулами производителей доступны через базу Excel и DbLib.

Библиотека находится в активной разработке. Перед применением проверяйте компоненты и ограничения моделей для конкретного проекта.

## Установка

1. Установите Git, Altium Designer 24, Microsoft Excel, совместимый по разрядности с Altium провайдер Microsoft ACE OLE DB и шрифт **Altium GOST Type A**.
2. Клонируйте репозиторий и перейдите в его каталог:

   ```sh
   git clone --branch main https://github.com/nomatin/ESKD-altium-libraries.git
   cd ESKD-altium-libraries
   ```

3. Откройте `MY_LIB.xlsx` в Excel, выполните **Ctrl+Alt+F9**, сохраните и закройте книгу. Откройте `MY_LIB.DbLib` в Altium, укажите путь к книге в `Data Source` и подключите библиотеку через **Preferences → Data Management → File-based Libraries**.
4. В панели **Components** выберите таблицу, найдите компонент и разместите его на схеме.

Не меняйте структуру каталогов: пути к УГО, посадочным местам и SPICE-моделям заданы относительно DbLib. Абсолютные ссылки на локальные даташиты после переноса необходимо обновить. Подробнее — [инструкция по подключению](ALTIUM_SETUP.md).

## Обновление

Перед обновлением желательно закрыть Excel и открытые в Altium файлы библиотеки. В каталоге репозитория выполните:

```sh
git pull --ff-only
```

После обновления может потребоваться заново открыть DbLib и обновить уже размещённые компоненты. Основная ветка для получения обновлений — `main`.

## SPICE

Модели доступны для резисторов, конденсаторов, диодов, светодиодов, части ферритов и двух защитных микросхем. Резисторы, конденсаторы, диоды, светодиоды, USBLC6-2SC6 и CDSOT23-SM712 проверялись в Altium Designer 24.4 MixedSim в статических, частотных и переходных режимах; набор испытаний зависит от модели. Модели ферритов сравнивались в ngspice с официальными моделями; в Altium они не проверены.

Подробности и результаты: [резисторы](Simulation/Resistors/README.md), [конденсаторы](Simulation/Capacitors/README.md), [диоды](Simulation/Diodes/README.md), [светодиоды](Simulation/LEDs/README.md), [USBLC6-2SC6](Simulation/USBLC6-2SC6/README.md), [CDSOT23-SM712](Simulation/CDSOT23-SM712/README.md), ферриты [TDK](Simulation/Ferrites/TDK/README.md) и [Murata](Simulation/Ferrites/Murata/README.md), а также [допущения симуляции](SIMULATION_ASSUMPTIONS.md). Тесты и отчёты находятся в папках `Tests/` и `Results/` рядом с моделями.

Успешный тест подтверждает только заданные условия проверки и не гарантирует соответствие всех характеристик реальному компоненту. Некоторые модели являются приближениями; изучайте их ограничения перед расчётом.

## Ограничения применения

- Перед изготовлением PCB сверяйте распиновку, посадочное место и `Notes` с даташитом конкретного артикула.
- Некоторые 3D-модели являются типовыми или приблизительными, включая модель переключателя DS1040-01RT. Проверяйте механические размеры и зазоры по даташиту.
- У USB4110-GF-A общий контакт SH соответствует четырём площадкам корпуса; его соединение с GND задаётся схемой. Отверстия 13 и 14 механические. Изоляционные домены ISOW1432 соединяйте согласно схеме производителя.
- Для CDSOT23-SM712 указанная мощность 400 Вт относится к импульсу 8/20 мкс и не является допустимой непрерывной мощностью. Температурные пределы компонентов проверяйте с учётом их условий и типа температуры в даташите.
