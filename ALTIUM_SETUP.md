# Подключение MY_LIB в Altium Designer 24

## 1. Подготовьте файлы

Сохраните изменения и закройте открытые в Altium SchLib/PcbLib. Если они были открыты до обновления библиотеки, откройте заново MY_LIB_Resistors.SchLib, чтобы загрузить исправленные номера выводов 1 и 2. Не сохраняйте поверх него старую открытую версию.

Файлы MY_LIB.DbLib и MY_LIB.xlsx должны лежать рядом с папками Symbols и Footprints. В Excel уже заполнены ссылки для 298 резисторов, 278 конденсаторов и двух микросхем U0002/U0003. Не нужно вручную назначать footprint каждому номиналу в SchLib: связью управляет строка Excel.

После любых изменений значений или формул откройте MY_LIB.xlsx в Microsoft Excel, выполните полный пересчёт Ctrl+Alt+F9, сохраните и закройте книгу. Altium читает сохранённые результаты формул и сам их не вычисляет.

## 2. Откройте подключение

1. В Altium выберите **File → Open** и откройте **MY_LIB.DbLib**.
2. В **Source of Connection** используйте **Use Connection String**: готовая строка использует ACE и Excel 12.0 Xml. Нажмите **Connect**; при установленном соединении будет показано Connected.
3. Если папка была перенесена, обновите Data Source в строке подключения. Провайдер — Microsoft.ACE.OLEDB.12.0; Extended Properties="Excel 12.0 Xml;HDR=YES;IMEX=1". Быстрый выбор Microsoft Excel в этой сборке может снова записать Excel 8.0; используйте готовую строку подключения.
4. В списке таблиц включены **Резисторы$**, **Конденсаторы$** и **Микросхемы$**. На листе микросхем доступны U0002 CP2102N-A02-GQFN24 и U0003 USBLC6-2SC6. U0001 LM358 — прежняя заготовка без моделей, её не размещать. Если драйвер показывает именованные диапазоны или служебные таблицы, не включайте их как дополнительные библиотеки.
5. На **Table Browser** убедитесь, что читаются 298 резисторов и 278 конденсаторов; заголовки распознаны как поля, а не как первая позиция.

В этой папке чтение XLSX через Microsoft.ACE.OLEDB.12.0 проверено. Если на другом компьютере появится Provider cannot be found / provider is not registered, нужен доступный Altium 64-разрядный провайдер ACE. Не переустанавливайте Office без выяснения разрядности и причины ошибки.

## 3. Проверьте сопоставления

Настройки уже записаны в DbLib. Для каждого включённого листа проверьте **Field Settings → Single key lookup**: Database field = ID, Part parameter = ID.

На **Field Mappings** должны быть такие пары:

| Database Field | Design Parameter |
|---|---|
| ID | ID — ключ |
| Library Ref | [Library Ref] |
| Library Path | [Library Path] |
| Footprint Ref | [Footprint Ref] |
| Footprint Path | [Footprint Path] |
| CommentBase | CommentBase |
| Comment | Comment |
| Description | [Description] |
| Value | Value |
| ESKD_value | ESKD_value |
| Type, Tolerance, Power, Voltage, Package | одноимённые параметры |
| Manufacturer, MPN, Dielectric, Notes | одноимённые параметры |

Comment и Description заполняются отдельными формульными столбцами R и S в Excel. ESKD_value и CommentBase передаются также как самостоятельные пользовательские параметры. Все исходные параметры доступны в Properties → Parameters. Visible On Add включено для Comment; остальные параметры доступны в свойствах и не выводятся автоматически текстом на схему. **Comment** указывается без квадратных скобок. Служебные поля моделей, напротив, сопоставляются с именами в скобках. Сохраните DbLib после проверки.

Library Path и Footprint Path в Excel относительны к папке MY_LIB.DbLib. Например, у R0001:

- Library Ref: R
- Library Path: Symbols\MY_LIB_Resistors.SchLib
- Footprint Ref: RESC2012X70N
- Footprint Path: Footprints\PBL - SMD Packages.PcbLib

## 4. Установите библиотеку

1. Откройте **Panels → Components**.
2. В меню панели откройте **File-based Libraries Preferences** / **Available File-based Libraries**.
3. На вкладке **Installed** нажмите **Install → Install from file** и выберите MY_LIB.DbLib.
4. В Components выберите MY_LIB.DbLib — Резисторы$ либо MY_LIB.DbLib — Конденсаторы$.

Если отдельной команды в меню панели нет, откройте **Preferences → Data Management → File-based Libraries**. Названия элементов могут немного отличаться в разных сборках AD24. Устанавливать каждый SchLib и PcbLib отдельно для работы через DbLib не требуется.

## 5. Проверьте размещение

1. На тестовую схему разместите R0001. Должны появиться УГО R, обозначение R? и Comment «10 кОм» и Description «Резистор 10 кОм ±1% 0805». В свойствах проверьте ID=R0001, Value=10k; номинал ESKD_value=10 кОм передан в Comment.
2. В Models проверьте footprint RESC2012X70N и его предварительный просмотр. Выводы УГО должны иметь номера 1 и 2.
3. Разместите R0002 (0603), R0004 (1206), C0001 (0603) и C0002 (0805). Так будут проверены все пять выбранных типов footprint. Проверьте, что в каждой модели есть медные площадки 1 и 2.
4. Соедините выводы тестовых R/C проводами с различными сетями и выполните **Design → Update PCB Document** в тестовом PCB-проекте. В окне изменений проверьте отсутствие Footprint not found и Unknown Pin, затем убедитесь, что обе сети попали на соответствующие площадки 1 и 2.
5. После изменения Excel сохраняйте и закрывайте книгу, затем обновляйте/переподключайте DbLib. Для уже размещённых компонентов используйте **Tools → Update Parameters From Database**, просматривая предлагаемые изменения. Замена графики УГО и моделей может требовать отдельного обновления компонентов из библиотек.

Если Comment остаётся «*», проверьте сопоставление Comment → Comment и формулу столбца R и настройки добавления/обновления. Если УГО или footprint не найдены, сначала проверьте точное имя и путь в строке Excel. Если драйвер отдаёт пустой или устаревший результат формулы, пересчитайте и сохраните книгу в Excel, затем переподключитесь.

## Текущий результат проверки

Проверены имена моделей, номера выводов в файлах SchLib, сохранность формул и чтение рассчитанных полей/ссылок через ACE OLE DB. Сам файл DbLib подготовлен, но ещё не открыт и не проверен в редакторе Altium; шаги 2–5 подтверждают его работу в вашей сборке. Микросхема LM358 пока не готова к размещению.

Официальная документация: [создание и настройка DbLib](https://www.altium.com/documentation/altium-designer/components-libraries/database-libraries/creating-defining), [установка и поиск библиотек](https://www.altium.com/documentation/altium-designer/schematic/components-file-based-database-libraries).

Если раньше была установлена библиотека DBUR.DbLib, удалите её старую запись из Installed и установите MY_LIB.DbLib по новому пути. После переименования заново откройте файлы библиотек в Altium. У уже размещённых компонентов проверьте Source Library и связь с базой: старый путь может потребовать повторного выбора библиотеки.

## Если сопоставления пустые и появилось сообщение об изменении базы

Закройте открытый MY_LIB.DbLib без сохранения и откройте исправленный файл с диска заново. Файл сохранён в Windows-1251, как локальные примеры DbLib, с точными русскими именами листов. В Field Mappings должны появиться Design Parameter, ID → ID и ссылки моделей. Микросхемы$ включён; сопоставлены исходные поля A:S и новые поля T:AD. Если поля снова пустые, сначала сохраните состояние Altium в отдельный файл MY_LIB_from_Altium.DbLib в этой папке: его формат позволит сравнить настройки с тем, что записывает ваша сборка.

Столбцы R (Comment) и S (Description) содержат формулы =D2 и =K2 у резисторов/микросхем, =D2 и =L2 у конденсаторов (номер строки меняется). Все исходные поля A:Q сохранены. Для новой строки R/C копируйте A:S; для микросхем копируйте A:AD. В Altium CommentBase и остальные пользовательские параметры находятся в Properties → Parameters; Description — системное описание.

В Properties → Parameters сохранены CommentBase, ESKD_value, MPN и остальные пользовательские поля. На тестовой плате проверьте передачу всех сигналов и общего SH на четыре площадки корпуса.
