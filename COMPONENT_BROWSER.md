# Видимые столбцы при выборе компонента

Настройки применяются к обеим библиотекам, панели Components и диалогу выбора компонента. Поля перечислены слева направо.

| Группа | Столбцы |
|---|---|
| Резисторы | ID → Сопротивление → Допуск → Корпус → Наименование |
| Конденсаторы | ID → Ёмкость → Допуск → Напряжение → Диэлектрик → Корпус → Наименование |
| Индуктивности | ID → Индуктивность → Допуск → Номинальный ток → Корпус → Наименование |
| Микросхемы | ID → Краткое описание → Наименование → Корпус |
| Ферриты | ID → Импеданс и частота → Допуск → Номинальный ток → Корпус → Наименование |
| Диоды | ID → Тип → MPN → Напряжение → Ток → Корпус → Наименование |
| Транзисторы | ID → Тип транзистора → MPN → Напряжение → Ток → Корпус → Наименование |
| Светодиоды | ID → Цвет → Прямое напряжение → Корпус → Наименование |
| Кварцы | ID → Частота → Начальный допуск → Рабочая температура → Корпус → Наименование |
| Разъёмы | ID → MPN → Количество контактов → Исполнение → Наименование |
| Переключатели | ID → MPN → Контактная схема → Напряжение → Ток → Исполнение → Наименование |
| Модули | ID → Краткое описание → Наименование → Корпус |
| Контрольные точки | ID → Диаметр → Наименование |

`Library Ref` / `LibRef`, пути, привязки моделей и футпринтов, поля SPICE, примечания и дублирующие имена в основной таблице скрыты. Сила света светодиода также скрыта. Параметры остаются доступны в данных компонента.

## Поля каталога

- Номинал отображается из `Comment`: читаемые единицы ЕСКД или `4R7`/`10K`, `uF`, `uH` для IEC.
- Полное текстовое имя — `Description`, допуск — `Tolerance`, корпус/исполнение — `Package`.
- `ShortDescription`: короткое описание функции микросхемы или модуля. Например: «Преобразователь USB–UART» / `USB-UART converter`.
- `ContactCount`: число сопрягаемых электрических контактов разъёма. Экран и крепёжные площадки `MP` не учитываются. Объединённые выводы считаются по отдельным контактам: у USB4110 — 16 контактов, выведенных на 12 контактных площадок платы. Контакты питания и дополнительные сигнальные контакты учитываются вместе: у XT30PW(2+2) — 4.
- `TransistorType`: общий тип транзистора, например `NPN`, `PNP`, `N-channel MOSFET`, `P-channel MOSFET`, `N-channel JFET`, `P-channel JFET`, `IGBT`. Поле не ограничено типом канала полевого транзистора.
- `RatedVoltage` / `RatedCurrent`: отображаемые напряжение и ток с указанием соответствующего параметра. У MOSFET — `VDS` / `ID`; у биполярного транзистора — `VCEO` / `IC`. Заполнять по данным конкретного компонента, сохраняя знак и паспортные условия. Допустимый ток зависит от условий даташита; табличное значение не гарантирует такой ток в любой схеме.
- `OperatingTemperature`: рабочий температурный диапазон кварца. Начальный допуск частоты отображается из `TolerancePpmAt25C`; он не заменяет температурную стабильность.
- Остальные поля профиля используют существующие параметры: `Voltage`, `Dielectric`, `RatedCurrentA`, `Color`, `ForwardVoltageTypicalV`, `DiameterMm`, `ContactForm`, `CurrentRating`, `Type`, `MPN`.

Заголовки в Altium соответствуют именам полей каталога. Параметры `VisibleOnAdd` определяют надписи на схеме и при настройке столбцов окна выбора не изменяются. Новые поля по умолчанию скрыты на схеме.

## Применение на другом компьютере

Конфигурация находится в `Settings/component_browser.json`, средство применения — `utils/configure_component_browser.cmd`. Python и установка дополнительных программ не требуются: используется встроенный PowerShell Windows. Настройки столбцов сохраняются в локальном профиле Altium и не переносятся одним файлом DbLib.

Закрыть Altium Designer и запустить двойным щелчком:

```text
utils\configure_component_browser.cmd
```

Перед каждым применением средство обязательно создаёт отдельную резервную копию в `Backup/ComponentBrowser/<дата-время>/settings.json` и проверяет её чтение. Если копия не создаётся или не проходит проверку, настройки не изменяются. При ошибке записи прежние значения восстанавливаются автоматически. Меняются только категории этой библиотеки; поиск и остальные сохранённые параметры профиля сохраняются. При следующем запуске Altium загружает новый порядок столбцов.

Для восстановления последней копии перед применением запустить `utils/restore_component_browser.cmd`. Чтобы выбрать конкретную копию, перетащить её `settings.json` на этот CMD-файл. Перед восстановлением также создаётся резервная копия текущих настроек.

Подробности и параметры запуска: `utils/README.md`.
