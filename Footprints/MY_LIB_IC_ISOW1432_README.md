# ISOW1432DFMR

В `MY_LIB_IC.PcbLib` добавлен футпринт **TI_DFM0020A** с 20 площадками и встроенной 3D-моделью.

Площадки 2,1 × 0,6 мм, шаг 1,27 мм, расстояние между рядами 9,7 мм; маска +0,05 мм, паста 0 мм; высота 3,55 мм. Геометрия соответствует примеру посадочного места TI DFM0020A.

Самостоятельная копия: `ISOW1432_Official_TI/TI_DFM0020A.PcbLib`. Исходный архив Ultra Librarian, чертёж TI и дополнительные STEP-файлы сохранены в `ISOW1432_Official_TI/`. Модели отдельно: `../3D/ISOW1432DFMR/`.

Подробная проверка: `../../work/ISOW1432DFMR_library_review.md`; резервная копия и контрольные суммы: `../../work/ISOW1432_library_manifest.json`.

Новый Altium не запускался. Проверено независимым импортом KiCad и 3D-рендером. Символ и строка базы компонентов не добавлялись.
