# Светодиоды Oasistek TO-1608BC / TO-2013BC

В базе MY_LIB.xlsx на листе «Светодиоды» добавлены HL0001–HL0014: по семь цветов для двух корпусов. Таблица MY_LIB_LEDs включена в MY_LIB.DbLib, ключ ID. Comment = ESKD_value = MPN; Description = CommentBase: «Светодиод Цвет Напряжение Яркость Корпус» по РД УР.016-24, п.4.6.3, стр.17. Например: «Светодиод Синий 3,2В 247мкд 0603». Использованы типовые VF и IV при IF=20 мА из каталога; артикул остаётся в MPN и Comment. В наименовании указан размер корпуса 0603 для TO-1608BC и 0805 для TO-2013BC, а не служебное имя footprint.

Источник цветовых и оптических параметров: каталог Oasistek 2021, печатные страницы 19–20 (страница PDF 12), https://www.oasistek.com/upload/2021_SMD_Lamp_Catalogue.pdf. IV указана как минимум и **типовое**, не максимальное значение. VF — типовое и максимальное. Условия: IF=20 мА, угол 120°. Поле TestCurrentMa означает ток измерения, а не максимально допустимый ток. Максимальные ток, мощность и температуры не перенесены по аналогии. Поле Voltage содержит типовое прямое напряжение, а не предельное напряжение.

Цвета: BF — синий 468 нм; PG — чистый зелёный 525 нм; MGE — жёлто-зелёный 572 нм; MYF — жёлтый 592 нм; MAE/MAF — янтарный 605 нм; MEE/MEF — оранжевый 623 нм; MRE — красный 630 нм. Для TO-1608 используются MAE/MEE, для TO-2013 — MAF/MEF. Суффикс также содержит класс яркости, а не только цвет. Белый вариант с иным обозначением линзы в эту серию BC не добавлялся.

## Соответствие выводов

Все 14 позиций используют сохранённое пользовательское УГО LED_1C2A: 1=C (катод, K), 2=A (анод). Сами SchLib не изменялись. LED_1A2C сохранено для компонентов с обратной нумерацией; для этих строк оно не требуется.

В MY_LIB_LED.PcbLib созданы варианты стандартных геометрий с числовыми обозначениями площадок. В LED_0603_1C2A и LED_0805_1C2A прежняя площадка K получила номер 1, A — номер 2. Таким образом, катод УГО соединяется с катодной площадкой, анод — с анодной. Ориентировать реальный компонент по метке катода. Существующие площадки A/K нельзя напрямую назначать УГО с выводами 1/2 без такого соответствия.

Заводская нумерация 1=K,2=A визуально подтверждена индивидуальными даташитами для девяти MPN: TO-1608BC-BF/PG/MGE/MYF/MRE и TO-2013BC-BF/PG/MGE/MRE. Ссылки и ревизии указаны в строках базы.

Для TO-1608BC-MAE/MEE и TO-2013BC-MYF/MAF/MEF используется **внутренняя нумерация библиотеки** 1=K,2=A; заводские номера не подтверждены. Это явно отмечено в Notes и PinMapping. Общий каталог показывает обе полярности P/N и не позволяет приписать единственную заводскую нумерацию всем цветам. Если документация конкретной поставки показывает 1=A,2=K, следует выбрать LED_1A2C и соответствующий footprint *_1A2C; такие варианты также подготовлены. Не менять только одну сторону связи.

## Геометрия

LED_0603_* повторяют LED-0603: площадки 0,8×0,8 мм, центры X=±0,85 мм, зазор 0,9 мм. LED_0805_* повторяют LED-0805-K: площадки 1,27×1,27 мм, центры X=±0,9525 мм, зазор 0,635 мм. Графика, маска, паста и 3D сохранены из исходных стандартных посадочных мест. 3D представляет стандартный корпус, а не точный цвет свечения конкретного MPN. В исходных потоках также есть объект pad 0 на механическом слое 71; он сохранён и не является третьим электрическим контактом.

Это принятые стандартные геометрии, а не точное воспроизведение land pattern каждой редакции даташита. У TO-2013BC встречаются существенно разные рекомендации между редакциями. Перед выпуском платы сверить конкретную поставку с её механическим чертежом. Исходная PBL - SMD Packages.PcbLib не изменялась.

Проверка проводилась чтением бинарных библиотек и импортом footprint в KiCad. Нативное размещение/ECO в Altium не выполнялось. После обновления базы переоткрыть DbLib без сохранения устаревшей версии и обновить подключение.
