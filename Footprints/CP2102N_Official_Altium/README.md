# CP2102N: официальный экспорт Ultra Librarian для Altium

Получен официальный формат **Altium Designer (native)** через Ultra Librarian Online Reader из предоставленного пользователем Silicon Labs BXL-архива.

В Altium откройте [cp2102n-a01-gqfn24.LibPkg](export/Altium/cp2102n-a01-gqfn24.LibPkg). Проект включает нативные PcbLib и SchLib. В папке также сохранена STEP-модель.

- [Посадочные места PcbLib](export/Altium/cp2102n-a01-gqfn24.PcbLib): `QFN24_4X4`, `QFN24_4X4-M`, `QFN24_4X4-L`.
- [Исходный архив экспорта](ul_cp2102n-a01-gqfn24.zip).
- [Независимая проверка по даташиту A02](CP2102N-A02-GQFN24_check.md).

**Результат проверки: ни один из трёх вариантов не совпадает полностью с рекомендованным посадочным местом CP2102N-A02-GQFN24 в даташите Rev. 1.5.** В исходном архиве есть только A01. Официальный экспорт сохраняет его геометрию: отличаются размеры меди, маска и паста; центральная площадка не имеет среза C0.25. Нумерация выводов и ориентация проверены.

Файлы внутри `export` не изменялись и не переименовывались под A02. Официальный символ A01 сохранён отдельно от ранее созданного пользовательского УГО. Перенос в существующие SchLib/DbLib/Excel не выполнялся.

Проверены целостность ZIP и побайтовое соответствие всех семи распакованных файлов исходному архиву. Контрольные суммы: `archive_sha256.txt`, `export_sha256.json`. Независимый импорт PcbLib проверен в KiCad 9; открытие и пересохранение в самом Altium не подтверждены.

Источник рекомендаций: [Silicon Labs CP2102N Data Sheet, Rev. 1.5, раздел 7.2](https://www.silabs.com/documents/public/data-sheets/cp2102n-datasheet.pdf).
