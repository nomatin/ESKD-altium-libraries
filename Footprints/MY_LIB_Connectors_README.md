# Библиотека разъёмов MY_LIB_Connectors

Файл: MY_LIB_Connectors.PcbLib
Компонент: USB4110-GF-A_GCT

Создана 21.10.2026 на основе Altium-экспорта Ultra Librarian для GCT USB4110-GF-A.

- Исходная геометрия меди, отверстий и порядок контактов сохранены.
- У площадок корпуса 15–18 исправлены ручные расширения: маска +0,05 мм на сторону; паста 0 мм.
- Высота компонента: 3,26 мм.
- STEP встроен в PcbLib и не требует внешнего файла для отображения.
- Модель взята из сторонней KiCad-библиотеки leptun/leptunKicadLib.pretty. Её происхождение зафиксировано в ../3D/GCT_USB4110-GF-A/SOURCE.txt.
- Положение: X=0; Y=2,2848 мм в Altium; поворот X=90°; высота установки 0.
- Библиотека открыта, модель встроена штатным диалогом и файл сохранён в Altium Designer 24.4.1. Совмещение дополнительно проверено независимым импортом/рендером KiCad.

Исходный экспорт и скачанный STEP сохранены отдельно. Подробный отчёт: ../../work/USB4110-GF-A_final_library_review.md (от корня MY_LIB/Footprints поднимитесь к workspace/work).
При связывании с символом площадки корпуса 15–18 должны подключаться к GND согласно чертежу GCT; установочные отверстия 13–14 являются NPTH.

## CONNFLY DS1037-01-09F — 24.10.2026

Добавлено посадочное место `CONNFLY_DS1037_01_09F` для угловой розетки D-SUB, 9 контактов. Чертёж CONNFLY: шаг 2,77 × 2,84 мм, отверстия Ø1,00 мм, крепления Ø3,20 мм / 24,99 мм. Пользовательская STEP-модель DS1037-01-09FNAKT74 встроена. Отклонение рядов исходной модели от чертежа 0,04 мм зафиксировано в [отчёте](CONNFLY_DS1037-01-09F/REVIEW.md). Добавлена строка XS0002 на листе «Разъёмы»: УГО X_9, выводы 1–9. По уточнению пользователя корпус не добавляется.


26.10.2026: для позиции XS0002 (DS1037-01-09F) назначен отдельный символ DS1037_01_09F с обозначением XS?. Геометрия и редактируемые имена контактов 1–9 взяты из текущего X_9 без изменений. Универсальный X_9 сохраняет X?. Обновите подключение DbLib перед новым размещением.
