# CP2102N-A02-GQFN24: исправленная копия по даташиту Rev. 1.5

Файл: `CP2102N-A02-GQFN24_DS15.PcbLib`.
Имя footprint внутри: **`CP2102N-A02-GQFN24_DS15`**.

Это пользовательская производная официального нативного экспорта Ultra Librarian из Silicon Labs BXL. Официальный оригинал A01 находится рядом в `../CP2102N_Official_Altium/export/Altium` и не изменён.

В Altium откройте PcbLib и выберите указанное имя в панели PCB Library. Для подключения к символу используйте именно новое имя и путь к этой PcbLib. Существующие УГО, DbLib и Excel этой правкой не изменялись.

## Что изменено

- Периферийная медь: 0,85 × 0,30 мм; шаг 0,50 мм; расстояние центров противоположных рядов 3,90 мм.
- Расширение окон маски: минимум 0,06 мм по всему периметру, ручное значение для каждого pad. Из-за дискретности координат фактически 0,06000242 мм.
- Паста периферии: 1:1 с медью.
- Центральная медь: 2,55 × 2,55 мм со срезом C0,25 со стороны pin 1.
- Паста центра: ровно четыре квадратных окна 0,90 × 0,90 мм с шагом 1,20 мм. Дополнительное окно 1 mil удалено.
- Шелкография и courtyard обновлены с учётом новых площадок. Исходное 3D-тело и встроенная STEP-модель сохранены.

Центральная площадка выполнена объединением трёх перекрывающихся SMD-площадок с **одинаковым номером 25**. Это позволяет получить срез в нативной геометрии Altium с привязкой всей меди к одной цепи GND. Поэтому физических pad-объектов 27, уникальных номеров 25. Паста от всех трёх центральных pad подавлена; четыре отдельных окна заданы на Top Paste. Это намеренная конструкция, а не ошибка нумерации.

Рекомендуемый трафарет по даташиту: 0,125 мм. Его толщину библиотека не задаёт; она указывается при заказе трафарета.

Размеры меди и координаты округляются до ближайшей дискреты Altium 2,54 нм; это существенно меньше производственных допусков. Размеры таблицы 7.2 приведены в колонке Min; для этой копии выбраны значения рекомендованного рисунка, без утверждения, что любая увеличенная площадка непригодна.
