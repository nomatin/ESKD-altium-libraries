## TestPoint — контрольная точка

Основание: ГОСТ 2.721-74, таблица 6а, пункт 7 «Индикатор контрольной точки». Графика проверена по скану официального издания Стандартинформ 2008 года, печатная страница 9 (страница PDF 11): закрашенная круглая точка с коротким вертикальным выводом вниз.

Источник: https://files.stroyinf.ru/Data2/1/4294852/4294852095.pdf

Один электрический вывод 1, тип Passive. Точка подключения находится в начале координат (0,0), длина вывода 100 mil. Имя и номер вывода скрыты. Диаметр закрашенной точки 40 mil выбран для сетки проекта; это не размер, предписанный приведённой таблицей ГОСТ. Шрифт Altium GOST Type A, 10, курсив.

Обозначение TP? — принятое для этого библиотечного компонента, а не утверждение о буквенном коде по ГОСТ. Comment скрыт. Тип компонента Altium — **Standard (No BOM)**: электрический компонент с передачей на PCB, исключённый из BOM. Геометрия, вывод и оформление исходного УГО сохранены. Посадочное место выбирается через DbLib: TP0001–TP0003 на листе «Тестовые точки», круглые площадки Ø1,0 / 1,5 / 2,0 мм из `Footprints/MY_LIB_TestPoints.PcbLib`.

Создано с нуля 22.10.2026. Проверены структура SchLib, наличие одного вывода и положение точки подключения. Предпросмотр `work/TestPoint_UGO.png` — реконструкция геометрии; нативная отрисовка Altium не проверялась.
