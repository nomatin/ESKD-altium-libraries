# CP2102N — предварительная проверка исходного BXL

Дата: 21 октября 2026. Статус: **PRELIMINARY / проверка исходника**.

**Официальный экспорт Ultra Librarian в Altium ещё не получен. Аудит итоговой Altium-библиотеки не выполнен. Этот документ не подтверждает готовность посадочного места к использованию.**

## Исходник и границы проверки

Проверен предоставленный пользователем архив `Interface Ultralibrarian CAD Footprints and Symbols.zip`, manifest Version 1.15. В нём есть `Interface/USB Bridges/USBXpress USB Bridges/CP2102N-A01-GQFN24.bxl`; отдельного `CP2102N-A02-GQFN24.bxl` нет. Внутреннее имя компонента также A01; атрибут производителя — Silicon Labs, copyright исходных данных — Accelerated Designs, 2016.

SHA-256 архива: `549bf0a4923651476c11b7c1e8a6ff79884a71c588b57a172aa545e73cd39afc`.

SHA-256 BXL: `402e17bcfbff1dd0596b1b1d51abfdfa28404281e61b5f71362d523f04113746`.

Для предварительного чтения использован распакованный текст `work/cp2102n_manufacturer/CP2102N-A01-GQFN24.decoded.txt`. Это техническое декодирование сжатого BXL, а не официальный экспорт Ultra Librarian. Проверены определения PadStack, размещение Pad, полигоны пасты и PinMap. Самописные пробные Altium-файлы не считаются результатом официальной конвертации.

Сравнение выполнено с [официальным CP2102N Data Sheet, Rev. 1.5](https://www.silabs.com/documents/public/data-sheets/cp2102n-datasheet.pdf), разделы 5.2 и 7.2, страницы 29–30 и 39–40. Даташит относится в том числе к A02; суффикс A01 в архиве нельзя скрывать переименованием файла.

## Геометрия исходных трёх вариантов

Единица BXL — mil, 1 mil = 0,0254 мм. Значения в миллиметрах ниже округлены до 0,000001 мм; небольшие отличия последних знаков исходных десятичных координат не являются геометрической ошибкой.

| Параметр | QFN24_4X4 | QFN24_4X4-M | QFN24_4X4-L |
|---|---:|---:|---:|
| Число площадок / нумерация | 25 / 1–25 | 25 / 1–25 | 25 / 1–25 |
| Шаг периферии, мм | 0,500000 | 0,500000 | 0,500000 |
| Периферийная медь, длина × ширина, мм | 0,700000 × 0,250000 | 0,750000 × 0,300000 | 0,650000 × 0,200000 |
| Расстояние между центрами противоположных рядов, мм | 3,950000 | 4,000000 | 3,900000 |
| Центральная медь, мм | 2,750000 × 2,750000 | 2,800000 × 2,800000 | 2,700000 × 2,700000 |
| Центральная медь: форма | квадрат | квадрат | квадрат |
| Добавка к окну паяльной маски относительно меди | 0 | 0 | 0 |
| Паста периферии | 1:1 | 1:1 | 1:1 |
| Четыре основных окна пасты в центре, мм | 1,175000 × 1,175000 | 1,200000 × 1,200000 | 1,150000 × 1,150000 |
| Шаг центральных окон пасты, мм | 1,375000 | 1,400000 | 1,350000 |
| Центральный зазор между окнами, мм | 0,200000 | 0,200000 | 0,200000 |

Дополнительно во всех трёх PadStack центральной площадки задано маленькое окно пасты **1 × 1 mil = 0,0254 × 0,0254 мм**, помимо четырёх полигонов. При официальном экспорте нужно проверить, как экспортёр обрабатывает это исходное окно; молча удалять его при оценке точности переноса нельзя.

Для ориентира исходные PadStack размеров периферии: `RX27p56Y9p84D0T` (27,55906 × 9,84252 mil), `RX29p53Y11p81D0T` (29,52756 × 11,81102 mil), `RX25p59Y7p87D0T` (25,59055 × 7,874016 mil). Центральные PadStack: `RX108p27Y108p27D0T`, `RX110p24Y110p24D0T`, `RX106p3Y106p3D0T`.

Нумерация исходника при виде сверху идёт против часовой стрелки: 1–6 слева сверху вниз, 7–12 снизу слева направо, 13–18 справа снизу вверх, 19–24 сверху справа налево. Pad 25 находится в центре; PinMap сопоставляет его GND. Угловая ориентация и номера согласуются с QFN24 pinout. Фактическое сохранение этой ориентации после официального экспорта ещё требуется проверить.

## Расхождения с рекомендацией Rev. 1.5

Таблица 7.2 задаёт расстояния рядов 3,90 мм, шаг 0,50 мм, периферию 0,30 × 0,85 мм и центральную площадку 2,55 × 2,55 мм. На рисунке 7.2 есть срез C0,25. Примечания требуют NSMD с зазором маски минимум 0,06 мм по периметру; для центра указаны четыре окна пасты 0,90 × 0,90 мм на шаге 1,20 мм, для периферии — 1:1.

Следовательно, **ни один из трёх исходных BXL-вариантов не воспроизводит полностью рекомендованный land pattern Rev. 1.5**:

- Во всех вариантах периферийные площадки короче 0,85 мм; только M совпадает по ширине 0,30 мм.
- Расстояние рядов совпадает только у L; Default и M отличаются на +0,05 и +0,10 мм соответственно.
- Центральная медь во всех вариантах больше 2,55 мм и не имеет среза C0,25.
- Маска определена равной меди; зазор минимум 0,06 мм не задан в исходном PadStack. Экспортёр может применить правила маски, поэтому итоговую маску необходимо проверить отдельно.
- Основные окна пасты и их шаг отличаются от рекомендуемых; присутствует дополнительное маленькое окно в центре.

Это различия старого исходника и актуальной рекомендации, а не доказанные ошибки экспортёра. Официальная конвертация должна быть оценена отдельно по точности переноса BXL и отдельно по соответствию даташиту. Полученный официальный экспорт следует сохранить без незаметных исправлений; корректировки по даташиту, если они потребуются, оформлять явно.

## Что остаётся проверить

После получения официального экспорта: открыть полученную `.PcbLib`/`.LibPkg`, проверить все три pattern, количество и номера площадок, единицы и повороты, фактические окна маски/пасты, сохранение полигонов и маркера pin 1, а также связь центральной площадки с выводом 25/GND. Затем повторить сравнение с указанными страницами даташита и зафиксировать результат уже для окончательного файла.

Открытие и сохранение итоговой библиотеки в Altium, её размещение на плате, передача связей и производственные выходные файлы на этом этапе не проверены.
